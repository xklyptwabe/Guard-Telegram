# Localization

Locale resources live in `src/i18n/locales/ru` and `src/i18n/locales/en`. Telegram language codes beginning with `en` select English; all others default to Russian. i18next uses Russian as fallback.

`npm run check:locales` compares leaf-key sets and fails on a missing translation. A public command, callback, module state, or user-visible error must add both locale entries in the same change.
